# Project 2: Exploratory Data Analysis (EDA)

## Objective

The objective of this project is to analyze the dataset and identify meaningful patterns, trends, distributions, and potential outliers using descriptive statistics and data visualization techniques.

## Tools Used

* Python
* Google Colab
* Pandas
* Matplotlib

## Dataset Overview

The dataset contains information about e-commerce transactions, including products, sales, payment methods, order status, customer details, and pricing information.

## Exploratory Data Analysis Performed

### 1. Descriptive Statistics

Basic statistical measures such as count, mean, standard deviation, minimum, maximum, and quartiles were calculated using the `describe()` function to understand the distribution of numerical variables.

### 2. Product-wise Sales Analysis

A bar chart was created to compare the total sales generated by each product.

**Observation:**

* Printer and Chair generated the highest sales.
* Laptop and Tablet also contributed significantly to total revenue.
* Phone recorded the lowest sales among all products.

### 3. Order Status Analysis

A pie chart was used to visualize the distribution of different order statuses.

**Observation:**

* The proportions of Delivered, Shipped, Pending, Returned, and Cancelled orders are fairly balanced.
* Cancelled orders account for the highest percentage (approximately 20.8%).
* Delivered orders account for the lowest percentage (approximately 19.2%).

### 4. Payment Method Analysis

A bar chart was created to analyze customer payment preferences.

**Observation:**

* Online payment is the most frequently used payment method.
* Cash is the second most preferred payment option.
* Credit Card, Debit Card, and Gift Card have similar usage frequencies.

### 5. Outlier Detection

A Box Plot was generated for the **TotalPrice** column.

**Observation:**

* Most transactions fall within the normal price range.
* A few observations appear above the upper whisker, indicating the presence of high-value outliers.
* These outliers represent unusually expensive purchases but are not necessarily incorrect values.

## Key Findings

* Product sales vary across different products, with Printer and Chair generating the highest revenue.
* Customer payment preferences are dominated by online payments.
* Order statuses are evenly distributed, indicating a balanced transaction workflow.
* The TotalPrice distribution contains a small number of high-value outliers.
* Overall, the dataset is well-structured and suitable for further analysis and predictive modeling.

## Conclusion

The exploratory data analysis provided valuable insights into customer purchasing behavior, product performance, payment preferences, and order processing. Visualizations and descriptive statistics helped identify important trends and detect a few high-value outliers. The dataset is clean, informative, and ready for advanced analytics and machine learning applications.
