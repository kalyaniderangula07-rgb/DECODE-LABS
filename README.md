# Projects Completed

## Project 1: Data Cleaning & Preparation

### Objective

Prepare a raw dataset for analysis by identifying and handling missing values, checking duplicate records, validating data types, and ensuring overall data quality.

### Tasks Performed

* Imported the dataset using Pandas.
* Checked for missing values.
* Filled missing values where required.
* Verified duplicate records.
* Validated data types.
* Saved the cleaned dataset for further analysis.

### Skills Learned

* Data Cleaning
* Data Preprocessing
* Missing Value Handling
* Data Validation
* Excel & Python Integration
